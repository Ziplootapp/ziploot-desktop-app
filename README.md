# ZipLoot Automated Web-to-Desktop App Builder (Tauri v2)

Convert any Web App, PWA, or Website URL into a 1.8MB Native Windows (.exe) desktop application using Rust Tauri & free GitHub Actions cloud compilation.

## 🚀 1-Click Automated PowerShell / Terminal Setup

### Windows (PowerShell):
`powershell
git clone https://github.com/Ziplootapp/ziploot-desktop-app.git
cd ziploot-desktop-app
powershell -ExecutionPolicy Bypass -File .\setup.ps1
`

### macOS / Linux (Bash):
`ash
git clone https://github.com/Ziplootapp/ziploot-desktop-app.git
cd ziploot-desktop-app
chmod +x setup.sh && ./setup.sh
`
